## 简介
IPSwitcher是一款基于Tauri 2.0构建的跨平台网络配置切换桌面应用。它允许用户创建多套网络配置方案并快速切换，支持手动IP和DHCP两种模式。本指南将帮助你在30分钟内完成完整的开发环境搭建、应用运行和首次配置创建。

## 环境要求

### 基础环境
- **Node.js**: 18+ (推荐使用LTS版本)
- **npm**: 9+ (包管理器)
- **Rust**: 1.77+ (Rust工具链)
- **Git**: 2.28+ (版本控制)

### 平台特定要求

#### macOS平台
- **Xcode Command Line Tools**: 开发工具链
- **macOS版本**: 10.15+ (Catalina及以上)
- **系统权限**: 管理员权限用于网络配置修改

#### Windows平台
- **Visual Studio Build Tools**: 2022+ (构建工具)
- **Windows SDK**: 最新版本
- **系统权限**: 管理员权限用于网络配置修改

### 技术栈版本
- **前端**: React 18 + TypeScript 5 + Vite 5
- **后端**: Rust (Edition 2021) + Tauri 2.0
- **数据存储**: SQLite (rusqlite, bundled模式)

## 版本号管理

### 版本号同步机制

IPSwitcher采用统一的版本号管理策略，确保前端、Rust后端和npm包的版本保持一致。版本号主要来源于Tauri配置文件，并通过Tauri API在前端显示。

### 版本号来源和位置

版本号主要存储在以下三个关键文件中：

1. **主版本号来源**：`src-tauri/tauri.conf.json`
   - `"version": "1.0.3"` - Tauri应用版本号
   - 前端通过 `@tauri-apps/api` 的 `getVersion()` 函数读取

2. **Rust包版本**：`src-tauri/Cargo.toml`
   - `version = "1.0.3"` - Rust crate版本号
   - 影响Rust二进制文件的版本信息

3. **npm包版本**：`package.json`
   - `"version": "1.0.3"` - npm包版本号
   - 影响包管理器和构建系统的版本信息

### 版本号同步步骤

发布新版本时，需要按顺序同步修改以下3个文件中的版本号：

```bash
# 1. 主版本号来源（前端 getVersion() 读取此值）
src-tauri/tauri.conf.json  →  "version": "1.0.3"

# 2. Rust 包版本
src-tauri/Cargo.toml       →  version = "1.0.3"

# 3. npm 包版本
package.json               →  "version": "1.0.3"
```

### 前端版本号显示实现

版本号在应用中的显示通过以下方式实现：

1. **应用启动时获取版本号**：
   ```typescript
   useEffect(() => {
     getVersion().then((v) => {
       setAppVersion(v);
       getCurrentWindow().setTitle(`IPSwitcher v${v}`);
     });
   }, []);
   ```

2. **版本号展示位置**：
   - 窗口标题栏：`IPSwitcher v1.0.3`
   - 欢迎页面：`v1.0.3` 显示在欢迎文本下方
   - 底部状态栏：`v1.0.3` 显示在状态信息右侧

3. **状态栏版本号组件**：
   ```typescript
   const versionLabel = version ? <span className="status-version">v{version}</span> : null;
   ```

### 版本号更新流程

```bash
# 1. 更新版本号
# 在上述3个文件中将 "1.0.1" 修改为新的版本号

# 2. 验证版本号同步
npm run tauri dev  # 启动开发模式验证版本号显示

# 3. 构建应用
npm run tauri build  # 生产构建

# 4. 验证最终版本号
# 检查生成的应用程序属性，确认版本号正确显示
```

## 创建第一个网络配置方案

### 1. 启动应用

```bash
# 开发模式启动
npm run tauri dev

# 或生产模式启动
npm run tauri
```

### 2. 创建配置方案

在应用界面中：
1. 点击左侧"新建"按钮
2. 填写配置方案名称
3. 选择网络接口
4. 选择IP模式 (手动/DHCP)
5. 填写网络参数
6. 点击"保存"并"立即应用"

### 3. 配置参数说明

#### 手动模式参数
- **IP地址**: 有效的IPv4地址
- **子网掩码**: 有效的IPv4掩码
- **网关**: 默认网关地址
- **DNS服务器**: 至少一个有效的DNS地址

#### DHCP模式
- 自动从DHCP服务器获取所有网络参数
