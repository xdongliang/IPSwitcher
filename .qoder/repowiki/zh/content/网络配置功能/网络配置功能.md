## 简介
本项目是一个跨平台的网络配置切换工具，允许用户创建、编辑、删除和应用网络配置方案（Profile）。系统支持手动配置（静态IP）与自动获取（DHCP）两种模式，提供网络接口发现、当前网络状态监控以及跨平台的网络配置应用能力。前端基于 React，后端使用 Tauri Rust 框架，通过命令通道调用平台特定的网络管理器完成实际的网络变更。

**更新** 本次更新显著改进了错误处理机制和权限管理，提供了更完善的平台特定网络操作和用户反馈。

### 配置方案管理流程
- 创建：前端收集表单数据，调用后端 create_profile 命令；后端进行校验并写入 SQLite

- 删除：前端调用 delete_profile 命令；后端从数据库移除
- 应用：前端调用 apply_profile 命令；后端根据模式选择静态或 DHCP，并在需要时提升权限

### 跨平台网络配置实现差异
- macOS
  - 接口发现：networksetup -listallnetworkservices
  - 当前配置：networksetup -getinfo
  - 应用静态：networksetup -setmanual + networksetup -setdnsservers
  - 应用 DHCP：networksetup -setdhcp + networksetup -setdnsservers Empty
- Windows
  - 接口发现：netsh interface ip show interfaces
  - 当前配置：netsh interface ip show config
  - 应用静态：netsh interface ip set address static + netsh interface ip set dns static
  - 应用 DHCP：netsh interface ip set address source=dhcp + netsh interface ip set dns source=dhcp

**更新** Windows 实现现在支持多个 DNS 服务器的添加，提供了更灵活的 DNS 配置选项。

### 权限管理
- 管理员状态检查：前端调用后端 check_admin_status

## 故障排除指南
- 无法列出接口
  - 检查平台命令是否可用（macOS 使用 networksetup，Windows 使用 netsh）
  - 确认管理员权限
  - 查看 AppError::Network 错误详情
- 应用配置失败
  - 确认接口名称正确且处于活动状态
  - 检查手动模式下的 IP、子网掩码、网关与 DNS 是否有效
  - 查看权限错误：AppError::PermissionDenied
- 管理员权限不足
  - 使用后端的提权机制或以管理员身份运行应用
  - 查看权限检查函数 is_elevated()
- 数据库异常
  - 检查数据库路径与权限，确认 migrations 成功执行
  - 查看 AppError::Database 错误类型
- DNS 配置问题
  - Windows 平台支持多个 DNS 服务器
  - 检查 DNS 服务器格式和可达性
- 托盘菜单问题
  - 确认托盘菜单重建功能正常工作
  - 检查配置仓库访问权限

**更新** 故障排除指南现在包含了新的错误类型和权限管理相关内容。
